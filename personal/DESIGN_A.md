# A 디자인 적용

사용자가 세 목업 중 선택한 밝은 금융 앱 디자인을 개인 데스크에 적용했습니다.

## 표시 변경

- 흰 사이드바, 블루 강조색, 밝은 배경, 큰 자산 숫자와 간결한 카드
- 대시보드, 포트폴리오, 거래일지, 자동매매, 매매 제안, 설정의 일관된 스타일
- 제안 근거로 이동하는 대시보드 카드와 제안 관측 순서 안내
- 390px 화면의 하단 메뉴, 44px 이상 주요 터치 영역, 화면 넘침 수정
- 로그인, 설치 아이콘, 시작 배경, 오프라인 안내의 같은 색상 적용

정적 CSS는 기존 허용 경로를 사용합니다. 로그인 스타일도 외부 정적 CSS로 제공하여 기존 CSP를 유지합니다. 서비스워커 캐시 버전만 올렸고 API 및 인증 HTML의 캐시 정책은 유지했습니다.

실제 화면은 기존 계좌·시세 데이터를 표시합니다. 목업의 예시 값이나 존재하지 않는 자산 시계열을 추가하지 않았습니다. 매매·계좌·인증 코드인 app.js, advisor.js, login.js와 서버·전략 파일은 변경하지 않았습니다.

## 검증

- 계좌 표시·모바일 인증·서버 관련 오프라인 테스트 22개 통과
- 합성 API만 사용하는 독립 브라우저에서 여섯 화면 × 1440px/390px 검증 통과
- 모바일 터치 영역, 가로 넘침, 접근 가능한 이름, 콘솔/HTTP 오류 검사 통과
- 연결 계좌 미설정·조회 실패·손익 미제공·증권사 불일치·불확실 주문 표시와 기존 시작 제한 확인
- 실제 로컬 앱의 대시보드·매매 제안 화면을 1440px/390px에서 읽기 전용으로 확인
- 실제 모바일 HTTPS 로그인 390px/1440px에서 CSP 오류와 화면 넘침 없이 표시되는지 확인
- 서비스워커 문법 및 정적 캐시 경계 확인
- 적용 전후 서버 PID, 매매 설정, 실행 상태, 밀봉된 연결 정보의 지문 동일 확인

이번 변경은 표시 계층에 한정됩니다. 매매 전략·주문 실행·정기 배치의 동작을 변경하지 않아 새로운 정기 매매 배치를 시험 실행하지 않았습니다. 실물 Android 기기의 설치 동작은 이번 디자인 검증 범위에 포함하지 않습니다.
