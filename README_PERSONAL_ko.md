# PRISM MY DESK — 나의 한국 주식 데스크

PRISM-INSIGHT를 개인용으로 확장한 한국 주식 분석·모의매매 도구입니다.
관심종목, 일봉 차트, 가격 관측 메모, 모의 포트폴리오, 거래일지와 CSV 내보내기를 한 화면에서 사용합니다.

## 실행

Python 3.10 이상이 필요합니다. 개인 데스크는 별도 패키지 설치 없이 실행됩니다.

```powershell
python -m personal.server
```

Windows에서는 `start-personal.cmd`를 더블클릭해도 됩니다. 표시된 주소
**http://127.0.0.1:8866** 를 브라우저에서 여세요. 창에서 Ctrl+C를 누르면 종료합니다.
이미 사용 중인 포트라면 `--port 8867`을 추가하세요.

기본값은 NAVER 공개 시세입니다. API 키 없이 시세·일봉을 읽습니다.
화면의 가격 기준 시각을 확인하세요. 휴장일·장 마감 후에는 마지막 시세가 표시됩니다.
해당 공개 API의 제공 범위·형식 변경이나 네트워크 장애 시 일부 데이터가 없을 수 있습니다.
가격을 확인하지 못한 종목의 주문은 차단하고, 실제 가격을 합성 데이터로 대신하지 않습니다.

인터넷 없이 화면과 주문 기능을 체험하려면 다음 명령으로 **데모 시세**를 선택하세요.

```powershell
python -m personal.server --provider demo
```

데모의 가격과 차트는 합성 데이터입니다. 실제 시장 데이터나 과거 수익률이 아닙니다.
시세 모드를 바꿀 때에는 서버를 종료하고 다시 실행합니다.
NAVER와 데모는 서로 다른 모의 계좌에 기록됩니다.

## 사용하는 방법

1. 종목 이름이나 6자리 코드로 검색하고 관심종목에 추가합니다. 목록에 없는 한국 종목은 NAVER 모드에서 코드로 검색할 수 있습니다.
2. 종목을 선택하면 일봉 차트와 기준 시각을 확인할 수 있습니다.
3. ‘가격 관측 메모’는 최근 20일 변화, 단순 이동평균, 단순 RSI와 변동성을 계산합니다. AI 보고서와 구분됩니다.
4. 모의 매수·매도에 수량과 이유를 입력하고 확인합니다. 서버가 확인한 시세로 즉시 모의 체결하며 주문 기록이 저장됩니다.
5. 포트폴리오·거래내역·일지에서 결과를 보고 CSV를 내려받습니다. 설정에서 데스크 이름과 모의 비용·비중 한도를 바꿀 수 있습니다.

시작 모의 현금은 **1,000만 원**입니다. 초기 보유종목이나 거래 수익을 꾸며 넣지 않습니다.
기본 종목당 최대 비중 30%, 모의 수수료 1.5bp(0.015%)는 연습용 설정값입니다.
비중 한도는 매수 수수료를 차감한 뒤의 총 평가자산을 기준으로 확인합니다.
세금·슬리피지·호가·부분 체결을 계산하지 않으므로 실제 증권사 체결·성과와 차이가 납니다.
원 단위 수수료는 올림 처리하며, 평균 매입 원가에 매수 수수료를 포함합니다.
동일 주문 재시도는 한 번만 기록되고, 잔액 초과·미보유 매도·시세 미확인은 거절됩니다.

## 원본 PRISM AI 분석 연결

키 없이 제공되는 ‘가격 관측 메모’는 AI 분석이 아닙니다.
원본 AI 보고서를 사용하려면 [원본 설치 안내](README_ko.md)의 의존성과 MCP/API 설정을 먼저 준비한 뒤 실행하세요.

```powershell
python -m personal.server --enable-prism
```

설정이 준비되면 화면에서 직접 요청한 종목의 원본 `cores.analysis.analyze_stock`를 별도 프로세스로 호출합니다.
AI 분석은 별도 서비스 설정과 비용이 필요할 수 있습니다. 결과는 로컬에만 저장합니다.
이 개인 데스크에는 실계좌 주문 경로가 없습니다. 원본 자동매매 배치·텔레그램·스케줄러를 시작하지 않습니다.
현재 작업에서 자격 증명을 입력하거나 유료 AI 분석을 실행하지 않았으므로, AI 연결의 실제 실행은 별도 설정 후 확인해야 합니다.

## 데이터·검증·라이선스

모의 계좌와 일지는 `runtime/personal/naver.sqlite` 또는 `demo.sqlite`에 저장됩니다.
이 폴더와 원본의 비밀 설정은 Git에서 제외됩니다. 같은 PC의 이 앱을 사용하는 모든 창은 같은 계좌를 공유합니다.
서버는 127.0.0.1에만 연결되며 외부 기기용 로그인 서버는 제공하지 않습니다.
계좌 데이터 백업은 서버를 종료한 후 `runtime/personal` 폴더를 복사하세요.

```powershell
python -m unittest discover -s personal -p "test_*.py" -v
```
