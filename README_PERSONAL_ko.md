# PRISM MY DESK — 나의 한국 주식 데스크

PRISM-INSIGHT를 개인용으로 확장한 한국 주식 분석·모의매매·자동매매 도구입니다.
관심종목, 일봉 차트, 가격 관측 메모, 모의 포트폴리오, 거래일지와 CSV 내보내기를 한 화면에서 사용합니다.

## 실행

Python 3.10 이상이 필요합니다. 개인 데스크는 별도 패키지 설치 없이 실행됩니다.

```powershell
python -m personal.server
```

Windows에서는 `start-personal.cmd`를 더블클릭해도 됩니다. 표시된 주소
**http://127.0.0.1:8866** 를 브라우저에서 여세요. 창에서 Ctrl+C를 누르면 종료합니다.
이미 사용 중인 포트라면 `--port 8867`을 추가하세요.

기본값은 NAVER 공개 시세입니다. API 키 없이 시세·일봉을 읽습니다.
화면의 가격 기준 시각을 확인하세요. 휴장일·장 마감 후에는 마지막 시세가 표시됩니다.
해당 공개 API의 제공 범위·형식 변경이나 네트워크 장애 시 일부 데이터가 없을 수 있습니다.
가격을 확인하지 못한 종목의 주문은 차단하고, 실제 가격을 합성 데이터로 대신하지 않습니다.

인터넷 없이 화면과 주문 기능을 체험하려면 다음 명령으로 **데모 시세**를 선택하세요.

```powershell
python -m personal.server --provider demo
```

데모의 가격과 차트는 합성 데이터입니다. 실제 시장 데이터나 과거 수익률이 아닙니다.
시세 모드를 바꿀 때에는 서버를 종료하고 다시 실행합니다.
NAVER와 데모는 서로 다른 모의 계좌에 기록됩니다.

## 사용하는 방법

1. 종목 이름이나 6자리 코드로 검색하고 관심종목에 추가합니다. 목록에 없는 한국 종목은 NAVER 모드에서 코드로 검색할 수 있습니다.
2. 종목을 선택하면 일봉 차트와 기준 시각을 확인할 수 있습니다.
3. ‘가격 관측 메모’는 최근 20일 변화, 단순 이동평균, 단순 RSI와 변동성을 계산합니다. AI 보고서와 구분됩니다.
4. 모의 매수·매도에 수량과 이유를 입력하고 확인합니다. 서버가 확인한 시세로 즉시 모의 체결하며 주문 기록이 저장됩니다.
5. 포트폴리오·거래내역·일지에서 결과를 보고 CSV를 내려받습니다. 설정에서 데스크 이름과 모의 비용·비중 한도를 바꿀 수 있습니다.

시작 모의 현금은 **1,000만 원**입니다. 초기 보유종목이나 거래 수익을 꾸며 넣지 않습니다.
기본 종목당 최대 비중 30%, 모의 수수료 1.5bp(0.015%)는 연습용 설정값입니다.
비중 한도는 매수 수수료를 차감한 뒤의 총 평가자산을 기준으로 확인합니다.
세금·슬리피지·호가·부분 체결을 계산하지 않으므로 실제 증권사 체결·성과와 차이가 납니다.
원 단위 수수료는 올림 처리하며, 평균 매입 원가에 매수 수수료를 포함합니다.
동일 주문 재시도는 한 번만 기록되고, 잔액 초과·미보유 매도·시세 미확인은 거절됩니다.

## 원본 PRISM AI 분석 연결

키 없이 제공되는 ‘가격 관측 메모’는 AI 분석이 아닙니다.
원본 AI 보고서를 사용하려면 [원본 설치 안내](README_ko.md)의 의존성과 MCP/API 설정을 먼저 준비한 뒤 실행하세요.

```powershell
python -m personal.server --enable-prism
```

설정이 준비되면 화면에서 직접 요청한 종목의 원본 `cores.analysis.analyze_stock`를 별도 프로세스로 호출합니다.
AI 분석은 별도 서비스 설정과 비용이 필요할 수 있습니다. 결과는 로컬에만 저장합니다.
AI 보고서와 개인 자동매매의 규칙은 별도입니다. AI 보고서가 자동으로 주문을 내리지는 않습니다.
원본 자동매매 배치·텔레그램·스케줄러를 시작하지 않습니다.
현재 작업에서 자격 증명을 입력하거나 유료 AI 분석을 실행하지 않았으므로, AI 연결의 실제 실행은 별도 설정 후 확인해야 합니다.

## 자동매매와 증권사 연결

거래 방식을 증권사 계좌로 저장하면 대시보드와 포트폴리오는 연결 계좌의 읽기 전용 잔고를 기본 표시합니다. 상단의 **표시할 계좌**에서 로컬 모의매매로 전환할 수 있으며, 이 전환은 자동매매 설정을 바꾸지 않습니다. 새로고침은 잔고만 조회하고 주문·신호 실행을 하지 않습니다. 조회 실패는 `조회 불가`로 표시하며 모의 잔고나 이전 값을 실계좌처럼 표시하지 않습니다. 수동 모의 주문·모의 거래내역·CSV는 모의 화면에서 제공합니다. 토스의 표시 자산은 API로 확인한 원화 거래 기준이며, 제공되지 않은 전체 평가·실현 손익은 `증권사 미제공`으로 표시합니다.

왼쪽 **자동매매**에서 로컬 모의 계좌, 한국투자 API 모의 계좌, 한국투자 실계좌, 토스증권 실계좌 중 선택합니다.
서버를 켜거나 다시 시작할 때 항상 중지 상태입니다. 먼저 대상 종목·예산·한도를 저장하고
**신호·주문 상태 점검**으로 주문 없이 자료와 조건을 확인하세요.

한국투자 API 모의·실계좌는 [한국투자증권 Open API](https://apiportal.koreainvestment.com/)에서
발급한 해당 환경의 App Key·App Secret과 계좌번호 8자리·상품코드 2자리를 연결 화면에 입력합니다.
계좌 연결은 인증과 잔고 조회만 합니다. 인증정보를 채팅이나 GitHub에 올리지 마세요.
Windows에서는 현재 PC 사용자에게 묶인 DPAPI로 암호화해 `runtime/personal/kis-connection.local`에
보관합니다. Linux/macOS는 사용자만 읽을 수 있는 0600 파일에 저장합니다. 이 파일은 Git에서 제외됩니다.
서로 다른 데이터 폴더도 같은 OS 사용자·한국투자 계좌의 동시 자동 실행을 차단합니다.

### 토스증권

1. [토스증권 공식 API 안내](https://developers.tossinvest.com/docs#description/introduction)에 따라 토스증권 WTS의 **설정 → Open API**에서 Client ID·Client Secret을 발급하고 이 PC가 사용하는 공인 IP를 **허용 IP 관리**에 등록합니다.
2. 이 앱의 자동매매 연결에서 **토스증권**을 선택하고 Client ID·Client Secret을 입력합니다. **계좌 목록 조회**는 읽기 전용이며, 표시된 계좌를 직접 선택한 다음 연결합니다.
3. 거래 방식을 **토스증권 실계좌**로 저장하고 신호·주문 상태를 확인합니다. 실계좌 시작 화면에서 현재 계좌·예산·한도와 토스 앱의 전체 미체결·예약·조건 주문을 확인합니다.

공식 문서에서 별도 토스 모의투자 서버는 확인되지 않았으므로 토스 모의를 가정하지 않습니다. **토스 주문은 실제 주문**입니다. 연결 확인만으로 주문하거나 서버 재시작 후 자동 실행하지 않습니다.

토스 인증정보는 한국투자와 별도의 `runtime/personal/toss-connection.local`에 동일한 로컬 보관 방식으로 저장합니다. 한 번에 선택한 하나의 연결을 사용하며, 미체결·불확실 주문 또는 자동 보유분이 남으면 계좌를 바꿀 수 없습니다. 같은 토스 클라이언트의 토큰은 하나만 유효하므로 다른 데이터 폴더의 동시 실행·키를 이용한 계좌 조회도 잠금으로 차단합니다. 다른 프로그램이 같은 인증키로 토큰을 발급하면 이 앱의 인증이 무효화될 수 있습니다.

토스의 **원화 거래 기준 자산**은 원화 현금 매수 가능 금액과 국내 보유 주식 평가액의 합입니다. API가 제공하지 않는 총예수금이나 해외 현금을 추측해서 더하지 않습니다. 종목당 비중과 일일 손실 한도는 이 기준 자산으로 계산하며, 해외 주식은 거래하지 않지만 전체 보유 종목 수 한도에는 포함합니다. 전체 계좌 순자산·실현손익을 의미하지 않습니다.

토스 시세는 KRX/NXT 통합이며 주문 API는 거래소를 직접 선택하지 않습니다. 이 앱은 확인된 정규 시간 09:00~15:20의 최근 시세로 국내 정수 수량 지정가 주문만 보냅니다. 주문 전에 저장한 의도 번호를 `clientOrderId`로 전달하며, 응답을 잃으면 재전송하지 않습니다. 토스 주문번호는 긴 문자열일 수 있습니다. 화면에서 정확한 주문번호를 연결하면 종목·방향·수량·지정가·주문 시각·실제 잔고를 확인합니다.

공식 API의 주문 조회에는 지원하는 주문 유형만 포함됩니다. 토스 앱에서 만든 일부 시간외 주문 등은 보이지 않을 수 있으므로 API 조회만으로 전체 외부 주문 부재를 보증하지 않습니다. **중지는 접수된 주문을 취소하지 않습니다.** 토스 앱의 전체 주문 내역에서 미체결·예약·조건 주문 및 취소 결과를 확인하세요. 이 기능은 조건주문을 등록하지 않습니다.

토스 인증·실제 체결·첫 정규 자동 점검은 아직 관측하지 않았습니다. 개발 검증은 실제 주문 없는 공식 형식의 가상 응답에 한정됩니다. 자세한 경계와 증거는 [토스 연결 검토](personal/TOSS_REVIEW.md)에 기록합니다.

### 공통 규칙과 주문 상태

기본 전략은 **개인 실험용 20일 종가 돌파**입니다. 전일까지 확정된 종가가 앞선 20개 종가의
최고값을 넘고 20일 평균보다 높을 때, 주문 시점 시세에서도 돌파와 평균 위를 유지하면 진입합니다.
자동매매가 매수한 수량만 관리하며, 확정 종가의 MA20 이탈 또는 설정 손절 조건에서 청산합니다.
고정 익절·물타기는 없습니다. 이 규칙은 원본 PRISM AI 전략의 복제나 검증된 수익 전략이 아닙니다.
[사전 검토 기록](personal/AUTOTRADE_CONTRACT.md)을 참고하세요.

- 1회 예산 안에 1% 비용 여유를 남기고 수량을 계산합니다. 실제 증권사 매수 가능 금액·수량,
  전체 계좌 보유 종목 수와 설정의 종목당 비중 한도를 다시 확인합니다.
- 일일 매수 금액·매수 주문 수 한도와 일일 시작 관측 평가자산 대비 손실 한도는 **신규 매수**를 막습니다.
  자동 보유분의 청산 점검은 계속합니다. 입출금도 평가자산에 반영되므로 손실 제한 판단에 영향을 줄 수 있습니다.
- 공개 NAVER 자동매매와 증권사 주문은 확인된 정규장 09:00~15:20에만 실행합니다.
  시세 지연·휴장·거래 정지·자료 결측은 보류합니다. 합성 데모만 시간 제한 없이 연습합니다.
- 한국투자에는 확인한 현재가를 **지정가**로 전송합니다. 접수는 체결이 아니며, 가격이 움직이면
  미체결로 남을 수 있습니다. 접수·부분체결·전송 결과 불확실 상태에서는 추가 주문을 멈춥니다.
- 정확한 증권사 주문번호의 체결 내역과 실제 잔고 수량이 맞아야 자동 보유 원장을 확정합니다.
  불확실 응답은 재전송하지 않습니다. 연결한 증권사 앱에서 주문을 확인한 뒤 화면의 주문번호 확인 기능을 사용합니다.
- **중지**는 새 주문 전송을 막습니다. 접수된 주문을 취소하지 않습니다. 미체결 확인·취소는 연결한 증권사 앱에서 하세요.
  손절은 서버의 주기적 점검과 지정가 주문이므로 갭·통신 장애·미체결에서 설정 손실률을 보장하지 않습니다.

브라우저를 닫아도 서버가 켜져 있으면 자동매매는 계속합니다. PC 절전·서버 종료 동안에는 실행되지 않습니다.
실계좌 시작 화면에서 계좌·전략·저장한 예산과 한도를 확인하고 직접 시작합니다.
현재 구현 검증은 격리된 모의·가상 API에 한정되며, 인증정보가 없는 상태에서 실제 증권사 주문을 시험하지 않았습니다.
먼저 한국투자 API 모의 계좌로 연결·미체결·체결 확인을 검증하세요.

## 데이터·검증·라이선스

모의 계좌와 일지는 `runtime/personal/naver.sqlite` 또는 `demo.sqlite`에 저장됩니다.
이 폴더와 원본의 비밀 설정은 Git에서 제외됩니다. 같은 PC의 이 앱을 사용하는 모든 창은 같은 계좌를 공유합니다.
PC 화면은 127.0.0.1에만 연결됩니다. 안드로이드용 별도 서버도 loopback에만 연결되며, 비공개 HTTPS 프록시와 기기 연결 코드로 접근합니다.
계좌 데이터 백업은 서버를 종료한 후 `runtime/personal` 폴더를 복사하세요.

```powershell
python -m unittest discover -s personal -p "test_*.py" -v
```

## 다양한 전략과 자율 매매 제안

자동매매 화면에서 20일 종가 돌파, 추세 눌림 반등, 평균선 회복, 조건 합의를 선택할 수 있습니다.
기존 돌파는 기본값이며, 새 전략은 로컬 모의매매 전용입니다. 증권사 모의/실제 주문은 기존 돌파를 유지합니다.
새 전략에는 완료된 일봉 55개가 필요합니다. 오늘의 진행 봉, 미래 날짜, 중복/역순 자료는 사용하지 않습니다.
기존 손절/MA20 청산, 자동 소유분 구분, 일일 한도와 미체결 보호는 유지합니다.

**매매 제안**에서 '지금 제안 계산'을 누르면 관측 종목을 네 가지 전략으로 비교합니다.
'자율 제안 시작'은 PC 서버에서 1분마다 다시 계산합니다. 앱을 닫아도 서버가 켜져 있으면 계속되며,
서버를 다시 시작하면 자율 제안과 자동매매 모두 정지합니다. 제안 생성은 주문을 전송하거나 체결을 정산하지 않습니다.
전략별 조건을 펼치면 관측값과 통과 여부가 나타나고, '판단 과정과 계좌 한도 보기'에서 자료,
전략 비교, 위험 점검, 최종 결론을 확인할 수 있습니다. 제안은 로컬 DB에 최근 100회 저장합니다.
공개 NAVER 시세와 연결 계좌의 읽기 전용 잔고를 사용하며, 실제 주문에는 증권사 시세와 매수 가능 금액을 다시 확인해야 합니다.
제안 수량/손실은 계획값이며 거래 비용·갭·슬리피지·미체결을 완전히 반영하지 않습니다.
규칙 계산을 전문가/LLM 의견이나 성공 확률로 포장하지 않습니다. 원본 AI 보고서는 별도의 요청형 기능입니다.
수익성 holdout과 앞으로 관측하는 모의 비교는 아직 검증 전입니다. [전략 사전 검토](personal/STRATEGY_REVIEW.md)를 참고하세요.

## 안드로이드 설치와 외부 접속

1. PC와 Android에 [Tailscale](https://tailscale.com/download/android)을 설치하고 같은 계정으로 연결합니다.
2. Windows에서 `start-personal-mobile.cmd`를 실행합니다. 기존 PC 서버가 실행 중이면 먼저 종료합니다.
   Tailscale HTTPS 활성화가 필요하면 표시된 관리 페이지에서 활성화합니다. 기존 다른 Serve 서비스는 덮어쓰지 않습니다.
3. PC의 **매매 제안 → 안드로이드에서 사용**에서 보안 주소를 확인하고 **휴대폰 연결 코드 발급**을 누릅니다.
4. Android Chrome에서 해당 HTTPS 주소를 열고 8자리 코드를 입력합니다. 코드는 5분간 한 번만 유효합니다.
5. Chrome 메뉴의 **앱 설치 / 홈 화면에 추가**를 선택합니다. 앱처럼 독립 창으로 실행됩니다.

HTTPS 원격 주소는 Tailscale에 연결된 기기에서만 접근합니다. 공개 인터넷 Funnel을 사용하지 않습니다.
기기 세션은 HttpOnly/Secure/SameSite 쿠키이며 12시간 후 만료됩니다. PC에서 모든 기기를 해제할 수 있습니다.
모바일 증권사 인증정보 입력/변경은 차단합니다. 키는 PC에 보관하고 모바일에는 전달하지 않습니다.
홈 화면 파일/아이콘만 캐시하며 계좌/제안/주문 API와 POST는 캐시하지 않습니다. 오프라인 주문 예약은 지원하지 않습니다.
휴대폰의 절전 여부와 무관하게 PC 서버가 켜져 있어야 제안 및 기존 자동매매가 동작합니다.
실제 Android 기기의 설치/외부 통신은 해당 기기에서 마지막 확인이 필요합니다.

일반 HTTPS reverse proxy를 사용하는 경우:

```powershell
python -m personal.server --mobile-origin https://your-private-host.example --mobile-port 8868
```

프록시는 `127.0.0.1:8868`로 전달하고 HTTP 외부 접속을 허용하지 않아야 합니다. 일반 PC 포트 8866은 공유하지 않습니다.
설치 조건은 [MDN PWA 안내](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable),
비공개 접속은 [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve)를 참고하세요.
